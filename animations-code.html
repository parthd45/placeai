Login & Register Page Animations - Complete Code

1. Lottie Animation (Illustration)

Both login and register pages use Lottie animations for the illustration section.

Login Page - Password Authentication Animation:

<!-- Load Lottie Player Library -->
<script src="https://unpkg.com/@lottiefiles/dotlottie-wc@0.8.11/dist/dotlottie-wc.js" type="module"></script>

<!-- Lottie Animation Component -->
<dotlottie-wc
  src="Password Authentication.json"
  style="width: 600px; height: 1300px"
  autoplay
  speed="1"
  transition="transform 0.3s ease-out, opacity 0.3s ease-out"
  loop
  style="padding-bottom: 30px;"
></dotlottie-wc>

Register Page - Appointment Booking Animation:

<!-- Load Lottie Player Library -->
<script type="module" src="https://unpkg.com/@lottiefiles/dotlottie-wc@0.8.11/dist/dotlottie-wc.js"></script>

<!-- Lottie Animation Component -->
<dotlottie-wc
  src="Appointment booking with smartphone.json"
  style="width: 600px; height: 600px"
  autoplay
  speed="1"
  transition="transform 0.3s ease-out, opacity 0.3s ease-out"
  loop
></dotlottie-wc>

Animation Properties:

  • autoplay - Animation starts automatically
  • loop - Animation repeats continuously
  • speed="1" - Normal playback speed
  • transition="transform 0.3s ease-out, opacity 0.3s ease-out" - Smooth transitions

5. Floating Label Animation (Register Page)

/* Label positioned inside input */
.form-group label {
  position: absolute;
  left: 14px;
  top: 50%;
  transform: translateY(-50%); /* Centered vertically */
  font-size: 15px;
  color: rgba(255,255,255,.7);
  transition: all 0.3s ease; /* Smooth movement */
  pointer-events: none;
}

/* Label floats up when input is focused or has value */
.form-group input:focus + label,
.form-group input:not(:placeholder-shown) + label {
  top: 10px;
  font-size: 12px;
  color: #7c3aed; /* Color change */
  transform: translateY(0); /* Move up */
}

Animation Effect: Label floats up and changes color when you focus or type in the input.

📋 Animation Summary

  • Lottie Animations: JSON-based animated illustrations (Password Auth, Appointment Booking)
  • CSS Transitions: All elements use transition: 0.3s for smooth animations
  • Transform Animations: Labels and buttons use transform for position changes
  • Shadow Animations: Inputs show glow effect on focus using box-shadow
  • Color Transitions: Buttons, links, and borders change color smoothly on hover
  • Backdrop Blur: Header and footer use backdrop-filter: blur(12px)
  • Opacity Animations: Eye button uses opacity changes on hover
  • Background Video: Fixed fullscreen video with parallax effect
